## 已知边界

- 按调用返回位置过滤，无设备 ID 限定；不能承诺只影响扬声器或某一个输出端点，也未排除相同实现的输入端点影响。
- 用户普通调音量、非目标来源与 dB 调用在独立进程中通过；不把这些测试扩大成微信内所有功能均已穷尽验证。
- 录音中途启用需要先等待空闲及音量稳定。该控制逻辑有模拟测试，真实 W06 场景仍待用户录音触发，属于本测试版尚未收口的关键验收项。
- 正常停用/退出有清理确认；独立宿主强制结束后约 0.2 秒恢复、lease 过期约 5.6 秒读回恢复，只适用于这次故障测试环境。
- 没有商业代码签名；没有做全网杀毒平台上传或 SmartScreen 声誉验证，不改变系统安全设置。
- 当前用户 Run 登记和 `--background` 分别测试，不声称已经注销/重新登录验证。
- 休眠唤醒、音频服务重启、Explorer 重启、长时间压力测试，以及真实微信退出重启尚未执行。
- 正常升级保留带时间戳的旧安装文件备份，以便恢复；这些恢复备份不因普通卸载而自动删除。

## 文件和运行身份

版本准入依据实际加载的 Weixin.dll；不使用某个机器固定安装路径或 PID。版本、哈希和 x64 架构必须同时匹配。audioses.dll 地址从活动输出的 vtable 取得，并验证系统路径和可执行内存；不使用固定系统 DLL 偏移。

安装目录按当前用户默认位于 LocalAppData/Programs/WeixinVolumeGuard。设置与日志在当前用户 LocalAppData/WeixinVolumeGuard。用户可以自行停用和卸载；没有驱动、系统服务或默认启动项。
